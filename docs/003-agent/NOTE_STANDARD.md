## 三、写作原则

- **费曼转述**：用自己的话重新讲，不复制原文。加类比、举例、场景化
- **💡 标记**：个人理解和补充用 `💡` 开头，与原文转述做视觉区分
- **信息密度**：不看原文也能理解核心脉络
- **问题导向**：每篇开头用具体问题说明在回答什么
- **遗留钩子**：每篇末尾列出没搞懂的问题，后续可回来验证
